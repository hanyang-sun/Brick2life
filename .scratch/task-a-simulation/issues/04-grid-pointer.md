# 鼠标指向固定格位与操作提示

三维主视图完成后的下一小步。只做悬停定位和提示，先验证屏幕坐标如何转换成固定棋盘格位，再接入单层增删移动。

## 验收

- 使用独立 WorkspaceCamera 的射线，棋盘 X/Z=0～10、格号 0～9，layer=0。
- 空格、积木顶面和侧面定位一致，最大侧面不误选邻格。
- 显示黄色 UI 格框与中文格位提示；未命中、屏幕外及右侧预览均清除提示。
- UI 不进入固定实验 RGB，不改变真实积木、相机或材质。
- 当前主编辑器实际 Play，检查常用窗口尺寸，保留证据和代码分段教学。
- 不固定尚未决定的移动交互，不新增编辑操作、识别、投影或多层。
