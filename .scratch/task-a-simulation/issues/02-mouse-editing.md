# 以工具模式编辑积木

用户已选定“添加／删除／移动”工具模式。主操作入口调整为三维工作台；预览图用于观察固定实验相机的输出。第一阶段只做单层，每格最多一块积木。继续采用分步教学，先完成操作视图，再讲解射线命中表面如何确定固定格位，最后接入动作与真实状态。

## 后续范围

- 操作区域中的屏幕位置通过操作相机转换为检测射线，命中棋盘或积木表面后确定 gridX、gridY；数据预留 layer，第一阶段固定为 0；排除工具面板点击。
- 工具模式与颜色选择；添加、删除和移动保持固定原点与格位，颜色种类可扩展。
- 第一阶段添加仅允许空底格，移动目标必须为空且处于棋盘内；删除已选积木。点击已有积木不自动在其上方加层。
- 编辑操作维护独立真实状态，供后续 Ground Truth 与 RGB 配对使用；编辑事件不直接提供给视觉算法。
- 移动采用拖拽还是两次点击尚未与用户确定；不要提前固定交互方式。
- 编码前完成对应 GitHub 检索和有限借鉴记录。

## 后续多层扩展

- 后续采用整格对齐、下方有支撑的规则堆叠，只删除或移动最上层积木；添加可放在空底格或已有柱的顶部，目标不得重叠。
- 扩展逐层真实状态与相机观测评价，初期交付不以多层功能为验收条件。
