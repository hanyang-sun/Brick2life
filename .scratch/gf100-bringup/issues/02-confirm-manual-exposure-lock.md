# 02 确认 GF100 曝光/增益/白平衡可手动锁定（一票否决项）

规格见 [spec](../spec.md)。

## 问题

`Assets/Scripts/Vision/PhotometricProfile.cs` 把"锁定"写成了**构造期断言**：

```csharp
// L38
if (!exposureLocked) throw new InvalidOperationException("真实相机必须锁定曝光、增益和白平衡。");
// L57（Fit）
if (!exposureLocked) throw new InvalidOperationException("真实相机必须锁定曝光、增益和白平衡后再标定。");
```

`CellProjection.cs` 同样带 `ExposureLocked`；`ProjectedLightRecognizer.cs:31-32` 在两者任一为 false 时直接 `Reject("相机曝光未锁定，光度标定不能用于这一帧。")`。

所以这一项**不成立则整条识别链不可用**，不是"效果差一点"。

GF100 参数表写的是：

- 可调参数：亮度 对比度 色饱和度 色调 清晰度 伽玛 **白平衡** 逆光对比 **曝光度**
- 自动曝光控制 AEC：支持
- 自动白平衡 AEB：支持
- 自动增益控制 AGC：支持

**"属性项齐全"不等于"能关掉自动"**。对照组：同芯片方案（AR0234）的 Kurokesu C3 明确写 "full auto **or manual** settings: exposure, gain, white-balance"，说明这取决于固件，不同产品差别很大。而中维奥柯、ELP 这类产品的参数栏都只列"自动曝光/自动白平衡/自动增益支持"，一个字都没提手动。

## 待做

向卖家索取**二者之一**作为证据：

1. Windows 下 AMCap / PotPlayer 打开该相机，**属性页截图**，要能看到曝光、增益、白平衡的**手动滑杆**且能取消"自动"勾选；
2. Linux 下 `v4l2-ctl -d /dev/video0 --list-ctrls` 的输出，要出现 `auto_exposure`（含 Manual 选项）、`exposure_time_absolute`、`gain`、`white_balance_automatic`、`white_balance_temperature`。

## 附加项：参数是否可写回

需求文档 01 节新增「相机重连后按记录复核或恢复」。所以不只要"能读"，还要**能写**——软件启动时能把记录下来的曝光/增益/白平衡重新设进去。需一并确认 UVC 控制项可写。

## Answer

**证据已取得（2026-11-10，卖家提供的 AMCap2 属性页截图）。结论：机制具备，尚待在设备上确认"取消自动后能锁住"。**

### 证据一：数据流格式（对应 issue 05）

截图里 1280×720 下**两种格式都列出来了**，且帧率跟着格式走：

| 颜色空间/压缩 | 帧率(B) | 输出大小 |
|---|---|---|
| **MJPG** | **60.000** | 1280 × 720 |
| **YUY2** | **5.000** | 1280 × 720 |

→ 与厂商参数表完全一致。**好消息是它可在 AMCap 里手动选 MJPG**，不必被动等驱动协商；但 Unity `WebCamTexture` 是否能选，仍需 issue 05 实测。

### 证据二：照相机控制（对应本 issue 的核心）

| 控件 | 截图值 | 判定 |
|---|---|---|
| **曝光(E)** | **−6** | ✅ **手动滑杆存在**，说明曝光是可控量而非只读 |
| 焦点(F) | 灰色不可用 | 说明**对焦是纯机械的**（旋转镜头），与参数表"可通过旋转镜头对准清晰度"一致 |
| 缩放 / 全曝光 / 倾斜 / 滚动 | 0 / 0 / 0 / 3 | 有值，可固 |
| 低亮度补偿(L) | 未勾选 | ✅ 保持关闭 |

每个控件右侧还有一列**「自动」复选框**——这就是"关自动"的机制。曝光、白平衡两行的自动需要**取消勾选**才算锁定。

### 证据三：视频 Proc Amp（顺带发现两个非中性默认值）

| 控件 | 截图值 | 评价 |
|---|---|---|
| 亮度(B) | 0 | 中性 |
| 对比度(C) | 50 | 中性（默认） |
| 饱和度(S) | 64 | 需固定 |
| **清晰度(P)** | **80** | ⚠️ **偏锐化**，会产生边缘光晕 → 破坏"全图统一 ambient/gain"假设 |
| **伽玛(G)** | **300** | ⚠️ 即 3.0，**暗部压缩很重**，不利于"投影黑时仍要有信号"（`signal > 1e-4`） |
| **白平衡(W)** | **4600** | 需取消自动后固定 |
| 逆光对比(B) | 0 | ✅ 保持 0 |
| 电力线频率（防闪烁） | **50 Hz** | ✅ 中国正确，保持 |

### 尚需在设备上做的确认

1. **取消曝光、白平衡的「自动」勾选**，确认数值能固定住（不弹回）；
2. 确认**增益(G)** 是否有值可调（截图里为空，可能随自动或不可用）；
3. 用 UVC 读回这三个控件的值，确认**能被程序写入**（需求文档要求"重连后按记录恢复"）；
4. 拔插重连，看参数是否保留 → 结论并入 issue 05 的 T3。

> 注意：AMCap 的「曝光 −6」刻度在不同固件上含义不同（有的是 100 µs 绝对值的对数档，有的是 log2 档位）。**必须记录"−6 对应的实际曝光时间"**，否则重连后无法按记录恢复。
