# 04 确认红米投影仪 3 Lite 可关闭 MEMC / 动态亮度

规格见 [spec](../spec.md)。

## 问题

需求文档 02 节（17:32 版新增）明确要求：

> 关闭动态亮度及会改变画幅的自动避障、自动入幕，再做标定。

而 04 节第 4 步又要求「记录投影指令及输出时间，实测显示和取帧延迟后，**将相机帧与对应投影内容匹配**」。

这两条合起来对投影机提出三个必须能关掉的功能：

| 功能 | 关不掉的后果 |
|---|---|
| **MEMC / 运动补偿** | 投影画面滞后于 HDMI 输入若干帧，且延迟随内容变化 → 帧-内容匹配的时间基准错掉 |
| **动态亮度 / 自动对比度** | 相机侧的 `gain` 项漂移，光度标定失效（这是 02 节新增"关闭动态亮度"的原因） |
| **自动避障 / 自动入幕** | 会实时改变画幅与位置，几何标定失效 |

红米投影仪 3 Lite 已知：投射比 1.2:1、1080p、180 CVIA、有**手动对焦**与**手动四点梯形校正**（这两项对"锁定"有利）。但 MEMC 与动态亮度的开关情况**未确认**。

## 对本机型尤其关键：避障会"常态触发"

`HY300Pro+` 标称「智能避障：**支持**」。避障的原理是用摄像头/TOF 检测投影面上的障碍物，然后**自动缩放并平移画面**去躲开。

而本项目的板面上**永远摆着积木**——从避障算法角度看全是障碍物。所以它不是"偶尔误触发"，而是**每次布局变化都可能触发**：

- 画幅从理论的 667 mm 变成别的值 → 几何标定作废；
- 可能持续微调而非一次到位；
- 需求文档 02 节要求关闭的正是「**会改变画幅的自动避障**」。

### 三层次提问

1. 菜单里有没有**独立的「智能避障」开关**？
2. 若没有独立开关，是否与「自动梯形校正」同组？能否**整组关闭**？
3. 关闭后**是否持久**，还是每次开机/切换信号源会恢复默认？

### 自查方法（比问客服更可靠）

摆好板子、放几块积木、接 HDMI 出画面 → 观察画面是否自行缩小/平移 → 再挪动积木，看画面是否跟着变。若跟着变且找不到开关 → 本机型出局。

### 关不掉时的退路及代价

| 办法 | 代价 |
|---|---|
| 物理遮挡避障摄像头 / TOF 窗 | 若与自动对焦共用传感器，会把对焦一起破坏 |
| 只关"自动校正"整组 | 若避障不属该组则无效 |
| 换机型 | 最稳 |

### 结论性观察

**"不支持自动避障"在本项目里是优点。** `HY300X` 标称不支持避障、不支持幕布自适应，这两项反而更贴合需求；`HY300Pro+` 分辨率与投射比更好，但多出的自动功能都是需要关掉的失控点。



查商品页参数或问客服，逐条确认能否关闭：

1. MEMC / 运动补偿 / 画质增强
2. 动态亮度 / 自动对比度 / 环境光自适应
3. 护眼模式（部分机型会按内容改亮度）
4. 是否有**低延迟 / 游戏模式**（优选；MEMC 关不掉时这是兜底）

同时记录：HDMI 输入下的**实测端到端延迟**（可用手机高速摄影拍"HDMI 输出瞬间"与"投影画面变化瞬间"的帧差）。
