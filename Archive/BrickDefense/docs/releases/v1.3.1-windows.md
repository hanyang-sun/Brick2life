# v1.3.1 · Windows 照片选择修复

日期：2026-10-12。Unity 6000.3.24f1，Windows x64，Mono，非开发构建。

## 问题与修复

v1.3.0 仅在 Unity 编辑器安装选图委托，Windows 程序读路径输入；输入为空时直接返回，用户点击“导入照片”没有弹窗或反馈。旧 Player 的原生窗口断言实际复现 `EXPECTED_FILE_DIALOG_MISSING`。

v1.3.1 在 Infrastructure 接入 Windows 自带 Unicode 选图窗口，以 Unity 窗口作为模态 owner，筛选 PNG/JPG/JPEG、要求文件存在、不更改工作目录。成功选择后继续原有图片加载流程；取消保留照片与分析结果，并显示提示；选图错误由 UI 捕获。Windows 隐藏原路径输入框，不再要求手动输入路径。Editor 保持原委托，其他平台不编译 Windows API。

候选比较和有限适配依据见 [Windows 选图研究](../research/windows-photo-picker-github.md)。没有增加第三方程序集、二进制或系统安装步骤。

## 验证

实际非开发 Player 验证：空输入点击出现“选择积木照片”系统窗口；首次取消；选入包内原始实拍 JPG 并识别出 10 块；再次取消保留原图及已分析结果；反复选择中文、含空格文件名的 PNG 和 JPEG，均正确加载。PNG 使用历史格式测试图，仅验证解码，不声称恢复了格纸识别模式。

构建日志报告 Success，运行时无异常。测试脚本、截图和最终包哈希检查见 `.scratch/windows-photo-picker/verification/README.md`。地图校对和战斗沿用 v1.3.0 已通过的回归；本修复未改变识别、地图或战斗算法。

## 交付

`Builds/BrickDefense-v1.3.1-Windows-x64.zip`。解压完整目录，双击 `BrickDefense.exe`，无需安装 Unity 或 .NET SDK。包含中文使用说明、实拍示例、第三方许可证及构建与文件哈希清单。退出旧版 v1.3.0 后使用这个版本。

本地交付，未提交或推送 GitHub。仍受单层等大积木识别范围限制；Android 相册和摄像头硬件实测不属于此 Windows 修复。
