# v1.3.0 Windows 桌面试玩版

日期：2026-10-12。平台：Windows x64。Unity：6000.3.24f1，Built-in 渲染，Mono 非开发构建。

## 包含内容

当前工作区的中文柔和策略 UI、正交相机旋转缩放、多出生点基础塔防、无格纸实拍识别，以及 v1.3 实物校对与游戏布局设计。实物校对记录两项准确率，设计阶段独立保存布局。

源代码基线为 `b5607ac`，包含尚未提交的地图校对工作区修改及此次 Windows 运行时材质修复，不能只用该提交复现本包。最终包内 `BUILD_INFO.json` 记录源资源哈希与本次构建信息。

## 构建方法

更新 `.scratch/layout-review/unity-check` 内 Assets、Packages 和 ProjectSettings。在隔离副本中设定版本 1.3.0、1280×800、窗口模式和可调整窗口大小，然后使用 Unity 内置命令：

```powershell
& 'D:\Unity\Editor\6000.3.24f1\Editor\Unity.exe' -batchmode -quit -projectPath 'D:\桌面\计算机图形学\BrickDefenseMVP\.scratch\layout-review\unity-check' -buildTarget win64 -buildWindows64Player 'D:\桌面\计算机图形学\BrickDefenseMVP\Builds\BrickDefense-v1.3.0-Windows-x64\BrickDefense.exe' -logFile 'D:\桌面\计算机图形学\BrickDefenseMVP\.scratch\windows-release\build-fixed.log'
```

构建入口场景：`Assets/Scenes/BrickDefenseDemo.unity`。Windows 构建模块已安装，Unity 主工程无需关闭；打包设置只作用于隔离副本。

## 构建时修复

首次构建实际运行时，Standard 着色器被裁剪，导致地图和战斗视图初始化出现空 shader 异常。新增 `Assets/Resources/BrickSurface.mat`，明确保留所需内置材质与着色器。第二次构建确认编译 Standard，实际程序正常显示积木、敌人和中文界面。研究依据见 [运行时着色器记录](../research/windows-runtime-shaders-github.md)。
