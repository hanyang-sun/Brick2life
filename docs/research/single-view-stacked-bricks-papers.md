# 固定单 RGB 相机下的多层积木识别：论文调研

调研日期：2026-10-15。

**阶段安排更新：** 用户在本次调研后决定先完成单层积木，并将拍摄识别与投影仿真分开验证；两者稳定后集成，再扩展多层。以下保留多层问题提出时的调研背景，作为后续扩展依据，不构成初期必须实现全部多层方法的要求。当前实施范围见 `.scratch/task-a-simulation/spec.md`。

## 1. 当前问题与阅读范围

当前实验计划是：Unity 中的 10×10 固定底面网格、等尺寸彩色立方体、整格堆叠且下方有支撑，只允许删除或移动每列最上面的积木；实验相机固定，连续输出 RGB，识别允许利用过去图像。玩家使用的操作相机与实验相机分开。

本次目标是为实验相机方向和实验规则提供依据，尚未确定相机角度，也未修改 Unity 场景或运行代码。只将原论文、论文官方开放版本及作者项目页作为结论来源。检索组合包括 LEGO / building blocks / stacked blocks / monocular / fixed camera / assembly tracking / reconstruction / temporal。

必须区分四种情况：

- 单台 RGB 相机，并保持固定视角。
- 单台 RGB 相机，但相机绕物体移动，实际获得多个视角。
- 单台 RGB-D 设备，同时提供颜色和深度。
- 使用说明书图像、已知零件或已知上一状态等额外先验。

后面三种都不能直接当作本项目“固定单视角、纯 RGB、只利用图像历史”的完整解决方案。相机标定、已知单位积木尺寸和支撑规则可以作为明确声明的先验；在线识别不能读取 Unity 积木真实坐标、点击编辑事件或真值布局来替代视觉推断。Ground Truth 供独立评价与离线训练使用。

## 2. 七篇研究的比较

| 研究 | 真正输入与观测方式 | 对遮挡或历史的处理 | 与当前任务的关系 |
| --- | --- | --- | --- |
| Learning to Build by Building Your Own Instructions，ECCV 2024 | 仿真图像、交互动作；全部实验使用固定相机角度 | 主动拆开结构，保存过程图像形成显式记忆 | 最接近“固定视角＋历史”，但有主动干预，不是被动看视频 |
| Translating a Visual LEGO Manual to a Machine-Executable Plan，ECCV 2022，MEPNet | 每一步说明书 RGB 图像、当前三维基础结构、待添加部件模型 | 利用之前的结构和连接约束确定新部件位置 | 可借鉴逐步推断与离散约束；输入先验比本项目强 |
| DuploTrack，UIST 2012 | Kinect 颜色与深度序列，用户还可改变手中模型姿态 | 跟踪模型，逐步记录增删操作 | 可借鉴时序状态，但不满足纯 RGB 与固定相对视角 |
| LEGO OASIS，VL/HCC 2011 | RGB+Depth 相机与对齐投影仪 | 识别新对象，帧间位置跟踪；深度分离前景与投影内容 | 与识别—投影闭环相关；深度依赖需明确排除 |
| MobileBrick，CVPR 2023 | 移动 iPhone 拍摄，多视角 RGB、LiDAR 深度、ARKit 位姿 | 移动观测获得不同表面信息 | 可参考图像与三维真值对齐；不满足固定视角 |
| Brickognize，Sensors 2023 | 散放零件 RGB 图像、合成训练数据 | 目标是可见零件检测，未实现完整堆叠恢复 | 可参考仿真训练集与域变化；不能据此保证识别隐藏层 |
| Single View Metrology，ICCV 1999 | 单幅图像、参考平面及方向、参考尺度和可定位的对应点 | 通过几何约束测量高度并分析不确定性 | 可参考层高估计的几何基础，不是隐藏积木的完整识别系统 |

各行的方法与限制依据见下文原文链接及章节。

## 3. 最接近的两条路线

### 3.1 固定视角＋主动显露＋图像记忆：InstructioNet

**论文：** Aaron Walsman 等，*Learning to Build by Building Your Own Instructions*，ECCV 2024。

**原文事实：** 作者在 LTRON 中让智能体先拆解陌生 LEGO，再利用自己保存的图像重建。修订后的环境移除了原先额外的手持零件图窗；尽管环境支持旋转相机，全部实验实际采用固定相机角度。模型将拆解期间的观测压入图像栈，随后比较当前图像与栈顶图像。原文没有在这些段落给出应直接照搬的相机俯角数值。[原论文，§3.1，PDF 第 4–6 页；§3.2，第 6–7 页](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/12536.pdf)

**适用解释：** 固定相机并不禁止利用时间变化。把当前场景与已观察到的历史结构联系起来，比每帧从零推测完整结构更合理。

**限制：** 这是仿真交互装配任务，模型能主动拆开物体，使隐藏零件变得可见；它不能证明静止遮挡情况下，仅靠过去相似图像就能恢复全部内部结构。训练还有专家监督；论文结果不能直接当成现实纯 RGB 在线识别的准确率。[原论文，§3.1、§3.4](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/12536.pdf)

**有限借鉴方向：** 采用历史观测、状态版本与关键帧；被遮挡但曾确认的积木可以保留为历史估计。无需现在引入其强化学习/模仿学习训练系统。

### 3.2 上一结构估计＋二维检测＋连接约束：MEPNet

**论文：** Ruocheng Wang 等，*Translating a Visual LEGO Manual to a Machine-Executable Plan*，ECCV 2022。

**原文事实：** 每一步输入包含当前结构的三维表示、待添加部件三维模型以及目标说明书图像。网络先预测二维关键点、掩膜与姿态信息，再用连接约束推断三维位置；投影采用弱透视，即缩放正交投影。关键点选在积木顶面中心，依据是说明书通常让新部件顶面可见，不能把这条设计规律套用到任意实拍遮挡。[原论文，§4.1–4.3，PDF 第 6–9 页](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136970663.pdf)

**重要评价限制：** componentwise、stepwise 评估使用真实的当前体素结构；setwise 会自回归地使用前一步预测，但 MTC 计错协议又会输入真实当前结构。因此不能摘出某一准确率，宣称模型在没有真实上一状态的条件下始终可靠。[原论文，§5.1，PDF 第 10 页](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136970663.pdf)

**有限借鉴方向：** 本项目已知积木尺寸、整格对齐和支撑规则，可以将可能位置限制为有限格位/层数，再依据图像匹配。在线“上一结构”必须来自识别器自身的历史估计；不能接入 Unity 真值绕过误差累积。这是本项目改造建议，并非论文已经验证的固定相机实时系统。

## 4. 容易被误认为符合要求的研究

### 4.1 DuploTrack：逐步装配跟踪依赖颜色与深度融合

**论文：** Ankit Gupta、Dieter Fox、Brian Curless、Michael Cohen，*DuploTrack: A Real-time System for Authoring and Guiding Duplo Block Assembly*，UIST 2012。

原论文使用 Kinect，融合颜色与深度来跟踪手中的模型，记录逐步添加，也处理移除。为控制复杂度，实验先限制为一种 2×4 Duplo 零件；即使如此，手部遮挡、反光、深度噪声仍会造成问题。系统会跟随物体在手中变化的姿态显示数字副本，所以也不是本项目固定棋盘、固定相对观测视角的等价设置。[原论文，第 1–2 页](https://grail.cs.washington.edu/projects/duplotrack/Gupta_DuploTrack.pdf)、[作者项目页及视频](https://grail.cs.washington.edu/projects/duplotrack/)

可以参考“保持状态、记录增删、给用户确认反馈”的组织方式。不能把去掉深度输入后仍能处理同色堆叠当作已被验证的结论。本轮作者 PDF 全文解析接口不稳定，以上限于已读到的开头方法说明，不扩展声称其全部后续算法细节。

### 4.2 LEGO OASIS：识别与投影闭环，但使用深度分离投影内容

**论文：** *Examining Interaction with General-Purpose Object Recognition in LEGO OASIS*，VL/HCC 2011。

原型使用 640×480 结构光 RGB+Depth 相机，安装在表面上方 30 英寸；配有对齐投影仪。深度用于将前景对象与静态背景及投影内容分离，也用于触摸检测。新对象出现时进行识别，帧间通过位置跟踪；识别特征包含梯度、颜色、形状和深度。[原论文，§IV Prototype Implementation，PDF 第 2 页](https://homes.cs.washington.edu/~jfogarty/publications/vlhcc2011.pdf)

它证明了对象识别与投影交互可以组成闭环，但不能据此假定普通 RGB 相机同样能轻易分离投影干扰。原文“安装在表面上方”的描述也不足以推出我们应使用某个精确俯角。

### 4.3 MobileBrick：一台设备采集多个视角，仍是多视角任务

**论文：** Kejie Li 等，*MobileBrick: Building LEGO for 3D Reconstruction on Mobile Devices*，CVPR 2023。

§3.1 明确是拿着 iPhone 绕物体移动，在 20–50 cm 距离采集 RGB、低分辨率 LiDAR 深度及 ARKit 内外参；§3.2–3.3 为实体模型建立匹配的数字 LEGO 模型，并将其与图像序列对齐。研究评估的是多视角重建、新视角合成及深度增强。[原论文，§3.1–3.3，第 4894–4895 页；§4](https://openaccess.thecvf.com/content/CVPR2023/papers/Li_MobileBrick_Building_LEGO_for_3D_Reconstruction_on_Mobile_Devices_CVPR_2023_paper.pdf)

可借鉴真值配对与相机参数记录。使用同一台设备不代表固定单视角；也不能拿其完整表面重建能力作为当前约束下的保证。

### 4.4 Brickognize：可参考合成数据，研究目标不是多层结构恢复

**论文：** *Brickognize: Applying Photo-Realistic Image Synthesis for Lego Bricks Recognition with Limited Data*，Sensors 2023，23(4):1898。

作者利用零件 CAD 模型合成 RGB 数据，并改变场景、相机、背景与灯光，结合少量真实数据训练检测。§4 中的零件位于平面表面；受控真实训练图像垂直拍摄，刻意避免相互遮挡以简化人工标注。论文不以恢复每一层隐藏积木及装配历史为目标。[原论文，§3–4，全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9967933/)

对本项目最有用的是：仿真平台应支持可重复布局和可控光照，输出图像与独立标注；单层检测基准与堆叠恢复实验需要分别报告。

### 4.5 Single View Metrology：用几何参考测量高度

**论文：** A. Criminisi、I. Reid、A. Zisserman，*Single View Metrology*，ICCV 1999；后有 IJCV 2000 扩展版本。本节依据 1999 年会议论文。

论文利用参考平面的消失线、非平行于该平面的参考方向及图像对应点，恢复相对几何尺寸；加入已知参考长度可获得绝对高度。§2 也说明结果适用于平行投影，不能将该方法简单理解成只有透视相机才能测高。§4 分析图像点定位误差如何影响测量结果。[原论文，§2、§3.1、§4，PDF 第 2–6 页](https://www-2.cs.cmu.edu/~ph/869/papers/Criminisi99.pdf)、[作者所在牛津 VGG 的论文目录](https://www.robots.ox.ac.uk/~vgg/projects/SingleView/pubbli.html)

**本项目推论：** 已知单位积木尺寸与固定棋盘坐标，可以为可见顶面/边缘提供尺度和格位约束；固定斜俯正交或透视视图都值得测试。严格竖直正交视图中的高度方向没有图像位移，属于需要特别检查的退化设置。论文不负责自动找到全部积木，更不恢复从未观察到的隐藏颜色。候选格位或历史模型估计错误时，几何计层也可能错误。

## 5. 对本项目的判断：事实与推论分开

### 5.1 从论文能确认的内容

- 已有固定视角的积木仿真实验，但其隐藏结构推断借助主动拆解和显式图像记忆，而不是保证一张图看穿所有层。[ECCV 2024，§3.1–3.2](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/12536.pdf)
- 规则尺寸、连接约束及之前结构是有价值的先验，但必须公开说明哪些是真实输入，哪些由识别器自己估计。[MEPNet，§4、§5.1](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136970663.pdf)
- 单设备、RGB-D、移动视角和固定纯 RGB 不是同一种实验条件。[MobileBrick，§3.1](https://openaccess.thecvf.com/content/CVPR2023/papers/Li_MobileBrick_Building_LEGO_for_3D_Reconstruction_on_Mobile_Devices_CVPR_2023_paper.pdf)

### 5.2 以下是本项目的几何分析与建议，尚未通过实验验证

1. **严格竖直正交俯拍对高度不敏感。** 同格上方再加一块同尺寸、同色积木，顶面投影可以完全重合；在没有可靠阴影、纹理或移动过程线索时，图像可能不提供层数变化证据。连续拍摄并不自动消除这种歧义，尤其是仿真中直接瞬间生成积木。
2. **固定斜俯视可增加顶面位移与侧面高度线索，但会增加相互遮挡。** 同色侧面可能合并，后排也可能被前排挡住；不应承诺任意布局都能完整识别。
3. **过去确认的层与当前可见层分开记录。** 建议保留“当前观测确认 / 由历史维持 / 未知或不确定”的状态。只有当前图像与历史共同支持时才更新，不把缺少证据解释成不存在。
4. **设定连续实验的起点与可见操作要求。** 从空板开始、逐块编辑、每次停留到稳定观测，是可控的第一阶段条件；它们仍不能让完全没有视觉变化的事件自动可辨认。丢帧、遮挡期间多次操作、从未知成品开始，应单列困难测试。
5. **同一序列只允许一台固定实验相机。** 可以在不同实验序列之间切换竖直与斜俯配置，比较角度；不能把同一时刻多个相机的结果融合后称为单视角识别。
6. **投影反馈要影响 RGB，但不能改写原始颜色真值。** 先比较投影关闭/开启的独立条件；是否允许短暂关闭投影采集“干净帧”需要团队另作协议选择，不能暗中加入。

## 6. 建议的最小对照实验

在确定实验相机方向前，先固定两种候选设置，在不同序列中分别测试；具体俯角待团队选择，不把论文中未公布的数值补成事实。

| 测试 | 检查的问题 |
| --- | --- |
| 同一格连续叠 1、2、3 层同色积木 | 画面是否真的包含可用于计层的变化 |
| 同格叠不同颜色，再逐层移除 | 历史颜色与隐藏层是否能保持 |
| 前后相邻两列，不同高度 | 前排是否遮挡后排，顶面是否仍能定位 |
| 遮挡或暂停采集期间修改，再恢复 | 历史预测何时失效，是否正确提示未知 |
| 同一布局投影开/关 | 投影是否影响颜色、轮廓和变化检测 |

图像输入只给识别模块；真实布局、鼠标编辑日志与对象 ID 仅存入评价记录。平台可同时导出完整真值和可见性辅助标注供分析，但后者也不能偷偷进入纯 RGB 识别输入。

优先统计可见顶层的格位/颜色准确率、各列层数准确率、完整体素占用准确率、变化事件准确率与延迟，并单列不确定率。完整体素评价需要明确包含多少由历史维持的隐藏状态，避免单看可见颜色准确率就宣称全部三维重建成功。
