# 俯视积木仿真测试集：数量、覆盖与划分方案

日期：2026-10-19。当前状态（2026-10-20）：**此大规模方案已按用户要求撤回，相关实现和生成数据已移除；本文仅保留数量研究记录，不作为当前执行计划。** 此前的相机、光照控制与单帧 PNG＋GT 导出继续保留。334 项光照检查、684 项相机检查属于程序验证，不是 B 的识别准确率。

第一方研究依据见 [测试集数量与覆盖研究](research/simulation-testset-size-and-coverage.md)。以下数量是针对本项目资源和范围提出的版本 1 计划，不是 ISO、NIST、COCO 或 ImageNet-C 要求的最低数量。

## 1. 先区分四种“数量”

- **基础布局组**：一份独立生成的格位＋颜色状态及其生成来源。由该布局派生的灯光、相机、图像噪声、旋转/镜像或重着色版本保留同一父组关系。
- **成像条件**：左右强度份额、环境光、总亮度、阴影、相机及后处理配置。多个条件有利于配对比较，不自动增加独立布局数量。
- **图像/逻辑帧**：实际提供给 B 的 RGB；可以引用已经存在的同内容图像。确定性重复渲染、复制文件和重复公共基线不用于虚增场景规模。
- **检测点/格子**：一幅图内有多个相关测量，不把 100 个格子或 25 个检查点当作 100 或 25 个独立棋盘。

NIST 比例估计的保守正态近似规划 `n≈1.96²×0.25/e²`，在独立随机二值试验、双侧 95% 等前提下，±5/±3/±2 个百分点约需 385/1068/2401 次独立试验。500 是本方案正式测试布局的起点，不能因为生成了 45000 张变体就宣称获得 45000 次 iid 试验的置信精度。手工挑选的黄金样例、分层压力样例也不直接具有简单随机抽样的总体含义。来源和零失败例子见研究文档。

## 2. 当前能力对应的完整光照矩阵

先固定同一相机、512×512 RGB、单层等大积木和四种颜色。主测试采用 Dual 模式：

| 因素 | 取值 | 数量 |
| --- | --- | --- |
| 左/右比例 | 0:100、25:75、50:50、75:25、100:0 | 5 |
| 环境倍数 | 0、1、3 | 3 |
| 总亮度 | 低、标准、高；当前强度预算 1.5、3、4.5 | 3 |
| 阴影 | None、Soft | 2 |
| 每布局条件数 | `5×3×3×2` | **90** |

0:100/100:0 仍是 Dual，零份额灯 enabled 但实际强度为 0。单 Left/Right 与方向光参考另列在工程回归中，避免把图像内容相同但控制模式不同的样本重复当作新的泛化证据。上述档位是合成参数，不是等照度或单调严重度的物理标准。

## 3. 主静态识别集：1000 组，90000 张

先固定组划分，后生成变体。即使 B 不训练神经网络，也使用开发、验证和封闭测试三部分分别用于实现、调阈值和最终评分。

| 划分 | 基础布局组 | 每组条件 | RGB 数量 | 用途 |
| --- | --- | --- | --- | --- |
| 开发 | 300 | 90 | 27000 | 开发识别、排查错误 |
| 验证 | 200 | 90 | 18000 | 选颜色阈值、补偿和拒绝参数 |
| 封闭测试 | **500** | **90** | **45000** | 冻结算法后评分 |
| 合计 | **1000** | **90** | **90000** | 不是 90000 个独立布局 |

这也是对原“同一布局 30 张”方案的主要修正：先增加基础场景，再扩充至完整现有条件。总数同时包含开发和验证，**45000 才是计划中的封闭测试 RGB 数量**。

布局分成下列 10 个主家族，每家族安排开发 30、验证 20、封闭测试 50 组；允许辅助标签重叠，但每个布局只占一个主家族配额。每组都应独立采样和验证，不把同一模板简单转四个方向就计为四个独立来源。

| 家族 | 内容与主要失败模式 |
| --- | --- |
| 稀疏随机 | 3～8 块，位置分散；漏检、空格误检 |
| 中等随机 | 9～25 块，多颜色、多间距 |
| 密集随机 | 26～60 块，相邻与局部连片 |
| 高密度 | 61～95 块，小空洞与窄缝；检验空格恢复 |
| 同色紧贴 | 同色直条、2×2/3×3 片块、随机连通块；检验合并/拆分 |
| 异色紧贴 | 不同颜色共享边、交错和分区；检验边界与颜色串扰 |
| 边缘集中 | 四条边分布、边缘与内部同色对照 |
| 角落集中 | 四角、角落小簇、中心与角落相同颜色对照 |
| 规则结构 | 横列、竖列、对角、L/U 形、环形、折线和通道 |
| 多簇及颜色失衡 | 孤岛、主色占多数、少数色只出现一两块；检验小类漏检 |

数量区间是生成配额，不限定某家族只允许某一密度。四种现有颜色尽量均衡，同时明确安排颜色失衡子组。单层、同尺寸、每格最多一块仍为正常输入边界。未知颜色、跨格、堆叠等放入拒绝/范围外试验。

不同 family 生成器可能得到同一格位＋颜色图，因此必须用内容哈希去重。哈希不能只使用运行时随机 brickId、LayoutVersion 或文件名。建议对排序后的格位、layer、occupied 和 colorId 规范化计算 `layoutContentHash`，另外保存 `parentLayoutGroupId` 和 seed。

封闭测试中的单个家族只有 50 组，不能声称每家族拥有 500 组的精度。若某家族需要更窄区间，应补充该家族的新布局组，而不是反复渲染同一组。

## 4. 公开黄金覆盖集：3285 个名义条件用例

此集用于检查已知边界和回归，允许开发时查看，不混入封闭测试的泛化分数。全部采用相同名义相机、50:50、标准光、环境 1 倍、阴影开。

| 用例 | 枚举依据 | 数量 |
| --- | --- | --- |
| 空板 | 一份空格位状态 | 1 |
| 单块全位置/全颜色 | 100 格 × 4 色 | 400 |
| 紧邻双块全位置/颜色 | 90 条水平邻边＋90 条竖直邻边，左右/上下有序 4×4 配色 | 2880 |
| 单色满板 | 4 色各一份 100 块布局 | 4 |
| 合计 | `1+400+180×16+4` | **3285** |

这能完整覆盖单块角落/边缘、同色双块和异色双块相邻等基础问题。主随机集采用 3～95 块，从而与这些空/单/双块和单色满板用例分开。黄金样例是确定性功能覆盖，不应套用 iid 成功率公式。

日常开发可固定选取开发/公开黄金集中的 40 个布局和 6 个代表条件，作为约 240 帧的快速回归。它是现有集合的固定子集，不再另加到总图数。

## 5. 独立几何测试：初始 100 配置、9000 图

使用专用共面标记底板，不把标记样本混入普通积木颜色识别评分。4 个明确标识的点用于拟合 H，另 **25 个检查点（5×5）** 用于评测，替代原 9 点起步方案。

- 检查点覆盖中心、边缘、近角落；可先取 X/Z 为 1.5、3.25、5、6.75、8.5。四角拟合标记与检查标记不重叠；标记尺寸要先在 512 分辨率中验证可辨认。
- 初始抽取 100 个有效相机/底板几何配置，各配上述 90 种灯光，共 **9000 张**；完整检测时得到 225000 个点观测，但独立几何配置仍只有 100 个。
- 配置覆盖正俯视基准、受控的小倾斜、横纵偏移、视野和高度变化。正常组逐一验证底板、标记和目标都完整入镜；裁切情况单独计入异常组。相机保持俯视用途，不引入大范围环绕视角。
- 第一阶段所有点在 Y=0。顶面 Y=1 的高度诊断作为独立后续试验；报告 B 对高度的处理策略，不把底板 H 直接套用于顶面后混为同一精度指标。
- B 必须从 RGB 检测点。Unity 投影坐标仅供评分；25 个检查点不参与 H 的拟合、参数选择和提前调补偿。
- 单独记录“标准光标定后冻结 H”和“每帧重新标定”两类协议；同一份报告不能混合这两类结果。

指标包括检测率/缺失点、像素误差、板面误差（格）、均值/P95/最大值，以及中心/边缘/角落分区。无有效点时报告测量失败。首次可用 20 个配置预试验测量误差分布，再决定是否增补几何配置；100 是覆盖起点，不是 NIST 规定的均值或 P95 样本量。置信区间按相机配置/采集会话分组，不能把同图的 25 个点当作独立场景。

OpenCV 所述“至少 10 个良好标定图案”是内参/畸变拟合输入建议，不是本集的验收图数。C 的板面到实际投影落点仍需独立测量，这个相机到板面测试不能替代投影对齐验收。

## 6. 前后帧变化测试：3600 对、7200 逻辑帧

在预先选定的 200 个封闭基础布局上，每种变化使用 3 组已固定的光照配置，每对含前/后两帧：`200×6×3=3600` 对，最多 7200 次逻辑帧引用。

| 变化类别 | 应检查的结果 |
| --- | --- |
| 添加一块 | 仅相应空格变为占用，颜色正确 |
| 删除一块 | 仅相应占格变为空格 |
| 移动一块 | 源格释放、目标格占用；其他格稳定 |
| 改变一格颜色 | 占用位置稳定、颜色差异正确 |
| 无变化 | 不产生布局变化事件 |
| 只改变灯光 | RGB 变化但真实布局不变，检查虚假事件 |

按完整序列/父布局分组留出，禁止前帧进开发、后帧进测试。无变化及前帧可能与静态集同内容，允许引用已存在图像，不能重复计为独立样本。相同颜色积木的身份交换若 RGB 和格位/颜色状态不变，不要求 B 恢复不可观测的实例编号；评分以公共状态/事件合同为准。

内容复用只复用像素文件，每个逻辑帧的 frameId、时间、GT、顺序和预期变化仍分别记录。两帧试验只验证变化对，不能证明多帧去抖、持续跟踪或实时延迟；这些能力接通后应增加完整会话序列和时间指标。

异常拒绝后保留上一份有效状态、恢复后重新采集另列工程检查。当前 B→C 变化接口尚未接通，尚不能声称上述事件测试已经执行。

## 7. 后续成像与投影扰动覆盖

借鉴 ImageNet-C 的“类型×多级强度”组织方式；并非复制其室外天气类型或最低图数。在新增能力就绪后，每族先设 5 个非零强度，其他因素保持名义值，在同一批 500 封闭布局上配对评测。

| 计划族 | 说明和当前缺口 |
| --- | --- |
| 欠曝 | 相机成像处理，区别于减少灯强；未实现 |
| 过曝 | 检查高光裁切和颜色丢失；未实现 |
| 白平衡偏冷 | 相机颜色处理；未实现 |
| 白平衡偏暖 | 同上，不靠改标签颜色冒充；未实现 |
| 传感器噪声 | 模型、种子、参数固定；未实现 |
| 失焦模糊 | 模糊半径/核版本固定；未实现 |
| 运动模糊 | 静态俯视之外的压力工况，单列；未实现 |
| 桶形畸变 | 使用可记录的几何模型；未实现 |
| 枕形畸变 | 与桶形分开，匹配后续 B 的模型；未实现 |
| 分辨率降低 | 固定采样/缩放方法，坐标和标定同步；尚无批次配置 |
| JPEG/压缩退化 | 区别于当前无损 PNG 导出；未实现 |
| 材质反光 | 塑料表面粗糙度/高光，保持物理颜色标签；尚无试验控制/材质快照 |
| 底板外观 | 固定底板颜色/纹理版本，避免让背景匹配变成唯一线索；尚无试验配置 |
| 投影图案干扰 | 反馈实际进入采集 RGB；需 C 接入或明确的光学仿真，尚未实现 |

14 族×5 级×500 布局 = **35000 个派生样本**，是后续扩展量，不是本轮已生成图，也不是 35000 个新基础布局。新增因素先单独评测，再预注册有限组合，例如弱光＋噪声、偏色＋反光、边缘＋畸变、投影＋阴影；不做所有因素的全笛卡尔积。

强度级别需要结合目标设备或预试验定义，5 级本身不保证贴近实拍。记录处理顺序及 pipelineVersion；畸变、缩放和裁剪后，明确点坐标属于原始图还是处理后图，同步几何真值，不能沿用理想投影坐标去给已经畸变的图评分。

## 8. 异常/拒绝集与工程故障

后续初始安排 6 类×100 场景 = **600 个异常场景**，相应生成能力就绪后执行：遮挡；关键标记缺失/遮挡；底板或积木裁切；跨格/旋转/堆叠；未知颜色或非积木杂物；严重模糊/欠曝/过曝。每类保留子类型标签和预期结果。

它们不计入正常输入的准确率分母。应报告合理拒绝率、异常误接受率，以及正常样本的错误拒绝率。若 B 明确支持某种扰动，应按冻结后的支持范围重新标注期待行为，而不是无条件要求它拒绝。

损坏图像、尺寸错误、旧 calibrationId、帧号错配、采集中修改布局/相机/光照、写盘失败、取消中途批次等属于接口/工程故障测试，单列报告，不用损坏文件来凑视觉场景数量。

## 9. 数据组织、泄漏防护和报告

每条清单至少保存 datasetVersion、suite、split、parentLayoutGroupId、layoutContentHash、seed、frameId、cameraConfigurationId、lightingConfigurationId、参数值、路径和状态；将来增加 imagingProfileId/materialProfileId/pipelineVersion。配对序列另含 sequenceId、frameOrder、expectedCellDelta。

先分组，后生成全部变体。同组的光照、图像扰动、相机视图、前后帧、旋转/镜像和从同模板衍生的重着色版本进入同一 split；通过内容哈希检查跨划分重复。训练/调参/阈值选择不能读取封闭真值，B 输入包仅含 RGB 和约定公开标定。B 的检测点必须来自图像，保留的测试点真值由评分器读取。

报告分开呈现：

- 整板占用＋颜色全部正确率；占用 precision/recall；逐颜色结果与漏检/误检；颜色混淆矩阵。不要让大量空格掩盖积木漏检。
- 按主布局家族、颜色、中心/边缘、光照条件及扰动级别分层的分母、失败数和结果。
- 几何检测率、像素/格误差、P95、最差位置及误差箭头图。
- 变化事件的正确性、虚假事件、拒绝后状态保持和恢复。
- 批次实际成功/失败/取消数、文件配对完整性、唯一布局数、内容重复数。

在具有相应抽样前提时报告置信区间。主集可在 10 家族内按基础布局分层/分组 bootstrap，比较两个 B 版本时按相同布局和条件做配对比较；各个灯光档的独立布局数最多仍为 500。该结果描述指定合成家族/参数分布，不能直接推断未见家族、真机或系统性渲染偏差。手工覆盖、异常和目标分布统计不合并成一个没有解释的“总准确率”。“封闭”表示冻结且不用于调参，不表示本地真值对开发者技术上不可访问。冻结版本后记录首次封闭评分，后续根据结果修算法时保留回归记录并另留新组检验泛化。

## 10. 实施顺序和资源

1. 实现可取消的批次调度、成功/失败结果、manifest、现场恢复、布局生成与内容/分组去重。
2. 用 30～100 帧预试验检验标签一致性、帧/配置对齐、进度和耗时。再执行公开黄金集与开发数据，预试验数量不替代正式测试。
3. 冻结 300/200/500 分组，生成主静态集；B 冻结参数后跑封闭部分并按组报告。
4. 加共面独立标记、有效几何配置抽样和几何评分，再接变化序列及异常恢复。
5. 随新增成像/投影能力补充计划中的扰动族，与真实设备对应布局对照。

本地现有 34 对光照检查样本的平均 PNG 约 46363 字节、GT JSON 约 28453 字节，合计约 74.8 kB/对。按此实测样本粗推，45000 对约 3.4 GB，90000 对约 6.7 GB；不含报告/备份，密集布局及噪声会改变 PNG 压缩率，不能把此值当容量上限。正式批次前应实测吞吐和存储；不承诺未经测量的采集时长。

上述数量是已撤回方案的研究记录，不代表当前项目持有的数据集或正在运行的采集任务。后续如需测试集，应重新确定较小的范围和数量；B/C 性能与真实设备精度仍需各自实际验证。
